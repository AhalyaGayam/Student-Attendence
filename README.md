# Student Attendance Management System

## Project Overview
The Student Attendance Management System is a web-based application developed using PHP and MySQL. It helps educational institutions manage student attendance records efficiently. The system provides separate login access for administrators and teachers.

## Features
- Admin Login
- Teacher Login
- Student Attendance Management
- Class Management
- Session and Term Management
- Attendance Reports
- Secure Authentication System
- User-Friendly Interface

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Software Requirements
- XAMPP/WAMP Server
- PHP 5.6 or Higher
- MySQL Database
- Web Browser

## Installation Steps

1. Download or clone the project.
2. Copy the project folder into the `htdocs` directory (XAMPP).
3. Start Apache and MySQL from XAMPP Control Panel.
4. Create a database named:

```sql
attendancemsystem
```

5. Import the provided SQL file into the database.
6. Open your browser and run:

```
http://localhost/attendance-php
```
